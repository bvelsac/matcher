# API

This directory contains the API endpoints/controllers for the matcher application.

## API Structure

- **requests**: Endpoints for managing requests (CRUD operations)
- **availabilities**: Endpoints for managing availabilities (CRUD operations)
- **matches**: Endpoints for viewing and managing matches
- **organizations**: Endpoints for organization management
- **freelancers**: Endpoints for freelancer/collaborator management
- **auth**: Authentication and authorization endpoints

Each controller should handle HTTP request/response and delegate business logic to services.
