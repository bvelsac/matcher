# Services

This directory contains the business logic for the matcher application.

## Key Services

- **MatchingService**: Core matching algorithm to match requests with availabilities
- **RequestService**: Business logic for managing requests
- **AvailabilityService**: Business logic for managing availabilities
- **OrganizationService**: Business logic for managing organizations
- **FreelancerService**: Business logic for managing freelancers
- **RecordService**: Service for maintaining records of the matching process

Services encapsulate the business rules and coordinate between repositories and external systems.
