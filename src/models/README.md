# Models

This directory contains the data models/entities for the matcher application.

## Core Entities

- **Request**: Represents specific tasks linked to a timeframe, defined by organizations
- **Availability**: Represents freelancer/collaborator availability information
- **Organization**: Represents organizations that create requests
- **Freelancer**: Represents freelancers and collaborators who provide availability
- **Match**: Represents the matching between requests and availabilities
- **User**: User authentication and profile information

Each model should define the structure and validation rules for its respective entity.
